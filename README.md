# Анимиран текстуриран хеликоптер

Курсов проект по BCSE51 „Компютърна графика“, ТУ-София.
Автор: Явор Калинов Георгиев, фак. № 121223073, гр. 39, КСИ.

Процедурно моделиран хеликоптер (само примитиви, без 3D файлове) с процедурни
текстури (без изображения), йерархичен граф на сцената, опростена физика на полета,
карта на сенките с PCF, прожектор, мъгла, режим ден/нощ и имитация на размазването
на ротора. C++17, OpenGL 3.3 Core, GLFW, GLM, glad.

## Сглобяване

Нужни са CMake 3.16+, C++17 компилатор и интернет при първото сглобяване
(CMake изтегля GLFW 3.4 и GLM 1.0.1 от GitHub).

**Visual Studio 2022:** File → Open → Folder… → тази папка → изчакайте CMake →
изберете `Helicopter.exe` → F5.

**Команден ред:**

```
cmake -S . -B build
cmake --build build --config Release
```

## Управление

| Клавиш | Действие |
| --- | --- |
| E | старт / стоп на двигателя |
| W / S | изкачване / спускане |
| A / D | завъртане наляво / надясно |
| Стрелки | наклон и движение |
| L | прожектор |
| N | ден / нощ |
| C | камера: преследване / орбита |
| Мишка | влачене – завъртане на камерата, колелце – приближаване |
| P / H / Esc | пауза / покажи-скрий контролите на екрана / изход |

## Структура

- `src/main.cpp` – прозорец, вход, основен цикъл
- `src/Mesh.*` – геометрия и процедурни примитиви
- `src/ProceduralTextures.*` – шум, fBm, генератори на текстури
- `src/SceneNode.*` – граф на сцената
- `src/Helicopter.*` – модел, физика, анимация
- `src/Camera.*`, `src/World.*` – камера; земя и хеликоптерна площадка
- `src/Renderer.*`, `src/Shader.*`, `src/ShaderSources.h` – рендериране и шейдъри
- `external/glad` – генериран OpenGL loader (glad 2, OpenGL 3.3 Core)
